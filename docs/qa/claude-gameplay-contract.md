# Gameplay contract handoff for Claude

User selected repository handoff while both implementations were still planning. Codex worktree: `../18-Forest RPG v2-codex-gameplay`, branch `codex/gameplay-repair`. This document is the integration boundary; Claude's acknowledgment has not been received. All additions are backward compatible for existing render consumers.

- Simulation owns `PortalState = locked | reacting | open | transitioning`. Portal entities and render views add `portalState`, `roundComplete`, `entryEligible`; existing `active` remains an adapter for open/transitioning. `portal:stateChanged` and `round:completed` carry authoritative transitions. Rendering must never infer completion or unlock from animation completion.
- Locked approach radius 2.5 tiles, exit radius 3 tiles, reaction 600 ms; entry radius remains 0.8 tiles. Reaction rearms after leaving. Completion is all non-ghost enemies defeated plus all coins collected; completion latches until world replacement.
- All positions and colliders use tile units; no camera transforms. AABB bounds use min/max coordinates and strict overlap (touching is allowed). Trees use trunk footprint [0.25,0.55]–[0.75,1]; boulders [0.1,0.4]–[0.9,1]; horizontal logs [0,0.6]–[1,1]; vertical logs [0.3,0.1]–[0.7,1]; stumps [0.2,0.5]–[0.8,1]; obstacle bushes [0.1,0.45]–[0.9,1]. Bounds are relative to tile origin. Canopies, small bushes, flowers, pebbles, and landmark holes have no collider. Legacy solid flags are supported for other intentional objects.
- Hills/cliffs/plateaus are solid, including during jumps. RAMP/LOG crossing tiles remain walkable. Ghosts intentionally phase through internal terrain but respect world bounds.
- `describeTerrain(world,x,y)` supplies category, elevation, walkability, tile ID, neighbor mask (N,NE,E,SE,S,SW,W,NW bits), exposed edges (N,E,S,W bits), convex/concave corners (NE,SE,SW,NW bits), and crossing classification. It reads final terrain, including post-generation edits; do not reconstruct solidity from textures.
- Enemy views retain `anim`, `animTimeMs`, `facing`, `hurtFlash`, and add AI state, attack phase, movement flag, and death flag. Animation timing resets on state changes. No renderer imports from simulation are needed.
- Debug gateway adds on-demand gameplay data: nearby colliders, terrain metadata, player tile, portal counts/state, region ID and enemy navigation paths/targets. Claude may draw this, but Codex will not edit overlays or visual systems.

Renderer views retain all existing fields. `__GAME__.getGameplayDebug()` is computed only on request. Its portal collider is the bounding box of the circular eligibility region; the portal controller's radius is authoritative. Ground enemies treat rivers as blocked, while player water traversal and ghost phasing remain explicit profiles. New generation is version 4; existing saved grids are preserved. Legacy explicit tree objects replace their duplicate FOREST base tile with GRASS so their trunk footprint is authoritative.
