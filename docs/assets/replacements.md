## Woodland boss nest (2026-10-29)

`public/assets/images/objects/nest/nest_{body,front,ground,cleared}.png` are purpose-made PNG assets generated using the built-in image-generation tool, then pixel-prepared with `node scripts/assets/prepare-nest-assets.mjs`. No new third-party artwork was downloaded; no third-party attribution/licence applies to these additions. The existing bug sprite sheets are unchanged.

The original generated transparent image is retained at `docs/assets/source/bug-nest-generated.png`. Production layers use aligned 96×80 native pixels, binary alpha, 32-colour palettes and nearest sampling. Mouth sprite anchor: (48,52), rendered 10 pixels above the logical enemy anchor to account for the unchanged beetle sheet's transparent lower padding. Ground roots/litter are below actors; the stump and front rim sort among actors. Cleared art adds subdued green growth. The stump now has a player-only stepped base collider covering the trunk, hollow and substantial roots. Enemy traversal and emergence remain unchanged; upper projections and transparent padding are excluded.

Generation brief: single isolated low decaying woodland stump insect dwelling on true transparency; top-down three-quarter RPG perspective; broken bark, dark hollow entrance facing viewer, exposed roots, olive moss, sparse ochre leaf litter; warm upper-left lighting and navy-brown shadows; crisp 1–2 pixel clusters and earthy palette; designed for a 96×80 native sprite, broad opening for the existing 45-pixel-wide beetle; no bugs, text, blur, gradients, ground rectangle or scenery.

## River banks, soil and surface weather (2026-10-29)

`waterArt.ts` retains the original four 32×32 water body textures and eight shallow/foam edge overlays, restoring their original contrast and detail at the user's request. It also generates 256 masks each for land-side banks and textured soil fringes. Pixel positions and palette are authored in project code, use nearest sampling, and have no external asset source or third-party licence requirement. Existing source images remain available for compatibility; production mud rendering uses grass beneath transparent, rounded soil fringes instead of stretching the legacy mud image over every cell.

`SurfaceWaterLayer`, `WaterLayer` and `WeatherLayer` draw puddles, crests, splashes and ripples from native world pixels. No downloaded or AI-generated bitmap assets were added for this work. The bridge and nest image assets are unchanged.

## Ghost grove pixel art (2026-10-29)

The procedural grey trunk/branches, block stones and schematic mushrooms in
`EncounterView.grove()` are replaced with existing pixel artwork from
[bluecarrot16 and contributors: LPC Flowers / Plants / Fungi / Wood](https://opengameart.org/content/lpc-flowers-plants-fungi-wood),
licensed **CC BY-SA 3.0**. The complete supplied contributor credits and an
adaptation notice ship at [public/assets/licenses/grove/NOTICE.txt](../../public/assets/licenses/grove/NOTICE.txt).
The source archive, original `plants.png`, source URL and SHA-256 hashes are
retained under `docs/assets/source/grove/`. The adapted sprites retain CC BY-SA
3.0. No AI image generation, procedural redrawing, recoloring or resampling is
used. `node scripts/assets/prepare-grove-assets.mjs` reproduces the crops.

The stump is the native 64×48 crop at (32,800). The source sheet is not a uniform
grid: individual fungi are isolated at (22,578), (33,578), and (54,580), each
8×8, then padded with transparency to a 16×16 bottom-centred frame. Existing
artist-painted half-opacity contact-shadow pixels are preserved. `GroveView`
uses unit sprite scale, integer world positions, nearest texture sampling, and
the existing character-foot depth convention. A restrained shared ground shadow
anchors the stump. Twelve mushroom sprites replace the old ring decorations.
Ghost phases/effects, generation, passable collision semantics, and saved site
definitions remain unchanged. Sprite lifecycle follows site IDs and world reset.

Alternatives inspected: existing project logs (baked grass and no established
source-license record); OGA DB32 trees/plants (larger forms and pronounced baked
shadows); Yar's tree rework (64×160, unsuitable native scale here); Kenney Tiny
Town (simpler 16px style); and itch.io Haunted Forest (different purple palette).
The curated gameplay screenshot is in `docs/images/gameplay.png`. Reproduce grove
captures with `tests/e2e/grove-art.spec.ts`; see [testing](../testing.md) for output locations.

## Runtime preload ownership and retained sources

The manifest preloads only runtime consumers. The eight old `hill_*` rim registrations, `ui_button_bg`, `bg_menu`, `bg_settings`, `vfx_acid_splat`, `vfx_eggsplosion` and static `item_coin` have been removed from preload bundles. Current terrain uses the cliff atlas, menus use the woodland DOM theme, effects are procedural, and animated coins use `item_coin_anim`. All original files remain available for reproduction and review. `font_pixel`, current player sheets, portals, biome packs and dynamically selected decor remain registered.

Identical mushroom images retain separate aliases because the runtime catalog chooses them dynamically. Clouds and legacy portal strips also retain their review/runtime catalog consumers. Historical player sources, approval files, screenshots and migration fixtures are evidence, not disposable build output.

Environment production scripts live in `scripts/assets/`. Historical player preparation lives in `scripts/player-art/`; the remaster, study import/packing, model import and final-sheet tools now stage output into ignored `artifacts/player-*` directories. The legacy sanitizer stages under `artifacts/asset-preparation/legacy`. Their optional first argument selects another staging directory. A shared guard rejects paths overlapping `src/`, `public/`, `docs/assets/source/` or `tests/fixtures/`, including symlink redirects and parent directories. Retained source inputs are read-only; staged artwork needs explicit review before promotion. The approved `face-continuity/pack.mjs` keeps its separate checksum verification contract.
